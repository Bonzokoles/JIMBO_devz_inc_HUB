# PUMO Analytics Dashboard

PUMO (Meble PUMO) analytics dashboard - Cloudflare Worker with D1/KV/R2 storage and GA4 integration.

## Features

- Real-time analytics dashboard
- GA4 integration
- Event tracking
- Revenue analytics
- Product performance metrics
- Custom reports

## Development

```bash
pnpm dev
```

Dashboard will be available at `http://localhost:3002`

## Deployment

Deployed to Cloudflare Pages at `pumo.jimbo77.com`

## Tech Stack

- TypeScript
- Vite
- Cloudflare Workers
- D1 Database
- KV Storage
- R2 Storage
- GA4 Data API

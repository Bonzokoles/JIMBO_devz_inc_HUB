Zen Browser OS

Privacy-focused browser startup page with local AI features and zero tracking

Overview

Zen Browser OS is a privacy-first browser homepage designed to replace default new tab pages with a feature-rich, zero-tracking alternative. All data is stored locally, with no external dependencies or analytics.

Built with Astro and deployed on Cloudflare Pages, it offers optional local LLM integration for private AI chat, customizable widgets, and bookmark management—all without compromising privacy.

Privacy Features

Zero Tracking

No external analytics, cookies, or fingerprinting. Your browsing stays private.

Local Storage

All bookmarks, settings, and data stored in browser's localStorage only.

No Dependencies

Self-contained application with no external CDN or third-party scripts.

Optional Local AI

Integrate with local LLMs (Ollama, LM Studio) for private AI chat.

Key Features

  • Local AI Chat: Optional integration with local LLM servers (no data leaves your device)
  • Bookmark Manager: Organize and search bookmarks with folders and tags
  • Search Aggregation: Unified search across multiple engines (configurable)
  • Customizable Widgets: Weather, clock, notes, todo list (all local-first)
  • Keyboard Shortcuts: Navigate entire interface without mouse
  • Dark/Light Themes: Multiple color schemes with custom CSS support

Technology Stack

  • Framework: Astro 4.0+ (static site generation)
  • Hosting: Cloudflare Pages (edge distribution)
  • Styling: Custom CSS with CSS variables for theming
  • Storage: Browser localStorage API (no server-side data)
  • AI Integration: Optional local LLM via HTTP API
  • Build: Vite + TypeScript

Local AI Integration

Zen Browser can connect to local LLM servers running on your machine:

  • Ollama: http://localhost:11434 (recommended)
  • LM Studio: http://localhost:1234
  • Text Generation WebUI: http://localhost:7860

All AI conversations stay completely private—no data is sent to external servers.

Use Cases

  • Privacy-Conscious Users: No tracking or external dependencies
  • Offline Work: Full functionality without internet (after initial load)
  • Local AI Experimentation: Test local LLMs in browser interface
  • Minimalist Workflows: Clean, distraction-free browser startup

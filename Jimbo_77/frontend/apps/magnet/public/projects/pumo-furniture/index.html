PUMO RAG System

Intelligent furniture catalog search using hybrid RAG architecture

Overview

PUMO RAG is an advanced Retrieval-Augmented Generation system designed specifically for furniture e-commerce. It combines the power of vector similarity search with traditional keyword matching to deliver highly relevant product recommendations based on natural language queries.

The system processes queries in real-time at the edge using Cloudflare Workers, ensuring sub-100ms response times regardless of user location. Integration with IdoSell e-commerce platform provides live inventory data and product information.

Architecture

The system follows a hybrid search pattern:

User Query → Worker → [Vector Search + Keyword Match] → DeepSeek R1 → Formatted Response

Components

  • Vector Search: Cloudflare Vectorize with 1536-dimensional embeddings
  • Keyword Matching: BM25 algorithm for exact term matching
  • LLM Integration: DeepSeek R1 via OpenRouter for query understanding and response formatting
  • Product Database: IdoSell REST API with 5000+ furniture items
  • Edge Deployment: Cloudflare Workers for global distribution

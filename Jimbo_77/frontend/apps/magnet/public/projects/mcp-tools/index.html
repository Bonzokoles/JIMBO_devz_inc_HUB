MCP Tools Suite

Model Context Protocol servers enabling AI assistants to interact with development environment

Overview

MCP (Model Context Protocol) Tools provide standardized interfaces for AI assistants like GitHub Copilot, Claude, and custom AI models to interact with VS Code workspace, navigate code, search documentation, and execute development tasks.

Each MCP server is a standalone service exposing specific capabilities through a unified protocol, enabling AI models to understand project context, access external services, and perform complex operations.

Available MCP Servers

workspace-navigator

Port 3889 | Node.js | FastAPI

Navigate multi-repo workspace structure with 7 Git submodules. JWT authentication, risk scoring, file watcher, FAISS integration.

  • Real-time workspace indexing
  • Risk assessment engine
  • Documentation auto-sync
  • WebSocket dashboard

rag-memory-mcp

Port 6100 | Python | ChromaDB

Knowledge graph with vector search for code context. Stores and retrieves project knowledge using semantic embeddings.

  • Vector similarity search
  • Knowledge graph storage
  • Context retrieval
  • Embedding caching

smart-coding-mcp

Port 6300 | TypeScript

Semantic code analysis and refactoring suggestions. AST parsing, code smell detection, optimization recommendations.

  • AST-based analysis
  • Code smell detection
  • Refactoring suggestions
  • Complexity metrics

cloudflare-r2

NPX | S3 API

Direct R2 bucket operations from VS Code. Upload, download, list, and manage Cloudflare R2 storage.

  • Bucket management
  • File upload/download
  • Metadata operations
  • Presigned URLs

openrouter-planner

NPX | OpenRouter API

Multi-model AI planning and execution. Route requests to optimal LLM, cost-based model selection.

  • Multi-provider access
  • Cost optimization
  • Model fallback
  • Usage analytics

perplexity-pro

NPX | Perplexity API

Web research integration with citations. Real-time web search and content extraction.

  • Web search
  • Citation extraction
  • Content summarization
  • Source validation

MCP Protocol

Model Context Protocol defines standard interfaces for AI-environment interaction: 

{
  "method": "tools/list",
  "result": {
    "tools": [
      {
        "name": "navigate_workspace",
        "description": "Navigate multi-repo workspace",
        "inputSchema": {
          "type": "object",
          "properties": {
            "path": { "type": "string" },
            "depth": { "type": "number" }
          }
        }
      }
    ]
  }
}

VS Code Integration

MCP servers are configured in .vscode/settings.json: 

{
  "mcp.servers": {
    "workspace-navigator": {
      "command": "node",
      "args": ["server.js"],
      "cwd": "U:/The_yellow_hub/workspace-navigator"
    },
    "rag-memory-mcp": {
      "command": "python",
      "args": ["-m", "mcp_server"],
      "env": {
        "CHROMA_HOST": "localhost:8000"
      }
    }
  }
}
